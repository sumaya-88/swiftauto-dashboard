# swiftauto-dashboard
SwiftAuto Traders car sales and profit analytics dashboard — Final Project for "Data Visualization and Dashboards with Excel and Cognos" | IBM Skills Network

📊 Dataset

Car sales data from the IBM Accelerator Catalog
Features include: Dealer ID, Model, Quantity Sold, Profit, Date, Recalls, Customer Sentiment
Data covers fiscal years 2018–2020


🛠 Technologies Used

Microsoft Excel (Charts & Pivot Tables)
IBM Cognos Analytics / Google Looker Studio
HTML & Chart.js (Interactive Dashboard)


📋 Project Parts
Part 1 — Excel Visualizations

Bar chart: Quantity Sold by Dealer ID
Line chart: Profit by Date and Model
Column chart: Profit by Year and Dealer ID
Line chart: Hudson Model Profits by Dealer ID

Part 2 — Dashboard (Sales & Service)

Sales KPIs: Profit, Quantity Sold, Avg Quantity
Service Analytics: Recalls, Sentiment, Heatmap
